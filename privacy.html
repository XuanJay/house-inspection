隱私權政策

  • 這個網頁沒有伺服器，開發者不收集、也收不到你的任何資料。
  • 勾選、備註、代號和照片存在你這台裝置的瀏覽器（localStorage、IndexedDB）。按頁面上的「清除」，或清除瀏覽器的網站資料，就會刪掉。
  • 第一次打開網頁、拍完照、以及按「存到 Google 雲端硬碟」時，網頁會用你登入的 Google 帳號和 drive.file 權限上傳。網頁只用這個權限處理它自己上傳的東西，以及你在選擇器裡點的那個資料夾：登入時確認你能在那個資料夾裡新增檔案（不能就不讓你開始，免得拍了照存不上去）；在那個資料夾裡建一個新資料夾；拍完照就上傳照片（登入還有效時自動上傳；重新整理過或登入過期，要按頁面底部的「☁ 待傳」才會繼續），照片在手機上刪掉或改了合格／缺失時，雲端那張會跟著移到垃圾桶或改檔名；上傳（之後更新）這次的初驗或複驗結果文字檔；按「存到 Google 雲端硬碟」時，會列出那個資料夾裡它上傳過的檔案，核對有沒有缺。網頁看不到你雲端硬碟裡的其他檔案。
  • 多支手機一起驗屋時，每支手機登入後會在那個資料夾裡存一個「驗屋進度」檔，內容只有：哪幾項勾了合格／缺失、各房間的插座數量、代號，以及一組隨機的裝置編號（不含照片、備註或帳號資料）。網頁會用頁面上公開的 API 金鑰、不用登入，讀那個資料夾裡各手機的「驗屋進度」檔，用來標出別支手機做過的項目；所以那個資料夾要維持「知道連結的人可以檢視」，知道資料夾連結的人也看得到這些檔。
  • 登入後取得的授權憑證只留在目前分頁的記憶體裡，關掉分頁就沒了。「這台裝置已經確認過能存進資料夾」的記號（之後上傳時發現沒有權限，這個記號會被清掉、下次重新確認），這一輪上傳到哪個資料夾、哪些照片已經傳過，以及這支手機的裝置編號和進度檔編號，存在你自己的裝置上。
  • 上傳的資料從你的瀏覽器直接送到 Google，不經過開發者。Google 怎麼處理這些資料，以 Google 隱私權政策為準。
  • 要撤銷授權，請到 Google 帳戶的第三方存取權移除「驗屋檢查表」。
  • 本應用程式使用和傳輸從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

使用條款

  • 這個網頁免費提供、照現況使用，不保證沒有錯誤或隨時可用。
  • 檢查項目和合格標準數字只供參考，不能取代專業驗屋或法規、合約原文。
  • 上傳到你自己雲端硬碟的內容由你自己負責。
