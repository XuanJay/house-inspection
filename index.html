驗屋當日流程

點 ✓＝合格、✗＝缺失（再點一次取消）；按了 ✓ 或 ✗ 會出現拍照鈕，按 ✗ 還會出現備註欄。沒有的項目跳過即可。勾選和照片只存在這台裝置的瀏覽器裡。

  1. 白天去，光線比較好；時間預留半天。
  2. 先到配電箱，確認總開關與各迴路都有送電、水已經開。瓦斯或熱水器還沒開通的話，相關項目留到複驗。
  3. 先做放水測試：水槽、洗手台、浴缸塞住放滿水；浴室地排用寬版膠帶封住、蓄一層水（低於門檻）。先放著，繞一圈回來再看下方有沒有漏、水位有沒有降。浴室的地磚、壁磚要先用驗屋錘敲過再蓄水，水放下去就敲不到了。
  4. 從大門開始，一個空間一個空間照表走。
  5. 每一項都要拍照，合格的也要：按 ✓ 或 ✗ 會直接開相機；還沒拍的項目會標「還沒拍照」，底下也會顯示幾項沒拍。遇到缺失：按 ✗，項目前面會出現編號（例如 A3）→ 把同一個編號寫在紙膠帶上貼好 → 拍一張遠景（看得出位置），再按「📷 拍照」補一張近景 → 備註寫位置與狀況。合格的也可以寫備註，例如位置、量到的數值。插座先在「插座」那組填這間有幾個，再一個一個測。表上沒有、但要記的東西，用每個區塊最後的「補充」：填數量，再逐項寫備註、拍照。
  6. 建商人員在場的話，缺失盡量當場一起確認，約好修繕方式，記在驗收單上（本表備註也寫一筆）。
  7. 照片拍完就會自動上傳到雲端硬碟。登入超過大約一小時，或重新整理過頁面，要按底下的「☁ 待傳」才會繼續傳（會跳一次 Google 視窗）。走完按「匯出缺失清單」，再按「存到 Google 雲端硬碟」，把缺失清單存進同一個資料夾；看到「已存到」、底下也沒有「☁ 待傳」才算全部傳完。清單交給建商簽收，並約好複驗日期。複驗時切到最上面的「複驗」，貼上這份清單逐項核對。
多人分工與順序

工具只有一套時，按工具分工，不要按樓層分：每人帶自己那幾樣走完全部空間，同一類問題也由同一個人判斷，標準比較一致。每支手機在「初驗」→「基本設定」填不同的代號，再勾「我負責」，表上就只列出自己的項目。

  • A 量測＋門窗：雷射水平儀＋腳架、雷射測距儀、捲尺、水平尺。地坪平整與全戶高低差、牆面垂直、門、窗、大門、窗台與欄杆高度。
  • B 敲＋看表面：驗屋錘兩支、工作燈、手電筒。磁磚空心（含浴室、廚房、陽台、樓梯）、油漆與裂縫、天花板、櫃體與台面。
  • C 大電：插座測試器、驗電插頭、電表、E27 燈泡。每間先在「插座」那組填插座數量，再一個一個測；還有開關與燈座、冷氣插座、配電箱、排油煙機和熱水器等用電設備。
  • C 弱電：網路測線儀＋網路線。弱電箱、各房網路孔、電視牆、對講機。
  • C 水：水桶、彈珠、寬版膠帶、衛生紙、抹布、內視鏡、熱像儀、梯子、螺絲起子。所有放水、排水、蓄水、淋水測試，衛浴設備，浴室天花板維修孔。

只有三個人時：一人 A、一人 B，第三人把 C 的三項都勾。每個人都帶紙膠帶（一人一色）、油性筆和充飽電的手機。

順序

  1. 開場：C 大電到配電箱確認都有送電，C 水確認水已經開；每支手機設好代號和「我負責」。
  2. A 先在客廳中間架雷射量全戶高低差。量完之前腳架不能碰：B 拖驗屋錘、C 水提水桶都要繞開，等 A 喊「量完了」。
  3. B 先敲各間浴室和陽台的地磚、壁磚，敲完通知 C 水。C 水在那之前先做廚房（水槽放水、下櫃管線）和窗的軌道排水，收到通知才去浴室、陽台封地排蓄水、倒水看坡度。
  4. C 大電把配電箱「一次關一個迴路」放到最後做：插座會斷電，關之前喊一聲。順便做配電箱的「最後再看一次」。
  5. C 水最後回浴室看蓄水水位，用熱像儀掃隔壁牆面和門外地面。
  6. 看到不是自己範圍的缺失：叫負責的人來記，不要自己記，不然合併的清單會重複。表上找不到的東西，誰看到誰記在那個區塊最後的「補充」（每個角色都看得到）。
  7. 結束：照片拍完就會自動上傳；每支手機最後按「匯出缺失清單」→「存到 Google 雲端硬碟」，確認底下沒有「☁ 待傳」才離開。
